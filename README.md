# Tirek CRM
CRM для малого бизнеса Казахстана. Рабочая локальная версия на NestJS, PostgreSQL и Next.js.

Приватный GitHub: [AdilMoon/TirekCRM](https://github.com/AdilMoon/TirekCRM). Порядок коммитов и проверок — в [git-workflow.md](docs/git-workflow.md).

## Быстрый старт
Откройте терминал в **D:\Projects\TirekCRM**. На новом компьютере:
```sh
npm ci
npm run setup
npm run db:local
```
Оставьте базу запущенной. Во втором терминале:
```sh
npm run db:migrate
npm run db:seed
npm run dev
```
Сайт: http://localhost:3000. Демо-вход: owner@tirek.local; начальный пароль TirekDemo2026! (см. .env).
На текущем компьютере база и зависимости уже настроены. Seed не очищает данные.

## Структура
```text
TirekCRM/
├── backend/         NestJS: API, бизнес-правила, Prisma, миграции
├── frontend/        Next.js: страницы, компоненты, переводы
├── packages/        Общие контракты API и схемы проверки
├── docs/            Архитектура, запуск, план развития
├── tests/           Интеграционные и браузерные проверки
├── scripts/         Запуск, настройка, проверка структуры
├── .local/          Локальная база и результаты проверок (не в Git)
└── node_modules/    Установленные зависимости (не в Git)
```

## Возможности
Русский, қазақша, English; сохранение языка; клиенты с редактированием; поиск и страницы клиентов/заказов; редактирование открытых заказов; история действий; команда и одноразовые приглашения; задачи с исполнителями и сроками; заказы; частичные оплаты; расходы; сводка; настройки предприятия; смена пароля и управление своими сеансами; неизменяемые снимки актов с печатью/PDF. Даты: Asia/Almaty, валюта: KZT.
Акты являются черновиками без ЭЦП. Денежный поток не является бухгалтерской прибылью. ИИ и отдельное мобильное приложение ещё не реализованы.
