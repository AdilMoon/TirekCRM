# Зертханалық жұмыс 10

TirekCRM веб интерфейсін Microsoft Edge браузерінде тексеру. Жұмыс ауқымы пайдаланушының нақтылауымен бір браузермен шектелген; көп браузерлік үйлесімділік туралы қорытынды жасалмайды.

## Орта

- Жергілікті PostgreSQL және HTTPS: `https://localhost:8443`.
- Playwright және орнатылған Microsoft Edge (`channel: msedge`).
- 1366 × 900, 390 × 844 және 320 × 844 экрандары.
- Тек тестілер құрған ұйымдар; негізгі деректерге өзгеріс енгізілмейді.
- Пошта тест серверінде міндетті түрде `local` режимінде. `.env` ішіндегі Gmail параметрлері өзгертілмейді.

Тәуелділіктер орнатылғаннан кейін дерекқорды `npm run db:local` арқылы бөлек терминалда іске қосып, `npm run db:migrate` орындаңыз. HTTPS пен жергілікті түбірлік сертификатты дайындау: [https.md](https.md).

Қолданыстағы серверді тоқтатып, тест серверін PowerShell ішінде іске қосу:

```powershell
$env:MAIL_DELIVERY='local'
$env:PASSWORD_RESET_DELIVERY='local'
npm run dev:https
```

Жаңа терминалда, репозиторий түбірінен:

```powershell
$env:NODE_EXTRA_CA_CERTS=(Resolve-Path '.local/caddy/pki/authorities/local/root.crt').Path
$env:LAB10_LOCAL_MAIL='true'
npm run test:lab10
npx playwright show-report playwright-report/lab10
```

`LAB10_LOCAL_MAIL=true` - тек тестінің алдын ала шарты. Ол жұмыс істеп тұрған сервердегі Gmail жеткізуін өшірмейді. Сервердің өзін `MAIL_DELIVERY=local` режимімен іске қосу қажет. Сертификатты тексеру және rate limit өзгертілмейді. Жиынтық кіру лимитінің терезесі жаңаруы үшін басында 61 секунд күтеді. Басқа UI жиынтықтарымен бір уақытта орындамаңыз.

## Ақау және нәтижелер

DEF-UI-01: сервер `q` мәнін 200 таңбамен шектейді, бірақ іздеу өрісі 201 таңбаны қабылдады. TC11 түзетуге дейін HTTP 400 және ұзындық assertion қатесін көрсетті. SearchBox өрісіне `maxLength={200}` қосылды. Retest UI сұранысына 200, тікелей 201 таңбалы API сұранысына 400 күтеді. Серверлік валидация сақталды.

Жергілікті нәтижелер `.local/lab10/run/` ішінде, HTML есеп `playwright-report/lab10/` ішінде сақталады. Алғашқы Failed дәлелі `.local/lab10/before/` ішінде архивтелді. Бұл нәтижелер, тест құпиясөздері бар runtime trace, Word файлы және жергілікті дерекқор Git-ке қосылмайды.

Regression пәрмені:

```powershell
$env:TEST_WEB_URL='https://localhost:8443'
$env:PLAYWRIGHT_CHANNEL='msedge'
npx playwright test tests/browser/workspace.spec.ts tests/browser/onboarding.spec.ts
```

Қаржы фильтрлерін тексеретін бұрынғы тестте нәтижені тексеруден бұрын нақты параметрлері бар API жауабын күту қосылды. Бұл асинхронды жүктеуге байланысты тұрақсыздықты азайтады және сервер жауабының 200 екенін бөлек тексереді.

DEF-API-02: сол күту кезінде серверден HTTP 500 / Prisma P2028 қатесі тіркелді. Қаржы есебінің жолдары мен қорытындысы екі сұранысты транзакция орнына бір SQL statement арқылы алынады. Ортақ snapshot сақталады, бос бетте қорытынды жоғалмайды және Decimal мәндері дәл қалады. `tests/reports.integration.mjs` ішіндегі API келісімі, сүзгілер, оқшаулау, күндер және ірі сандар тексерілді.

Осы жұмыс барлық браузер, барлық құрылғы, қауіпсіздік аудиті немесе жүктемелік тексеру нәтижесі болып саналмайды.
