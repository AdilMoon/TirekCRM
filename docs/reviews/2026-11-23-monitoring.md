# Мониторинг платформы

Проверено 23 ноября 2026 года.

Добавлены официальный клиент метрик Prometheus для Node.js, защищённый endpoint, фоновый сбор показателей базы и очередей, а также Docker-профиль с Prometheus, Grafana и Blackbox Exporter. Данные хранятся в локальных томах. Наблюдение охватывает API, PostgreSQL, веб-приложение, HTTPS, ошибки, задержки, ресурсы процесса и доставку уведомлений.

## Проверки

- Отдельный ключ требуется для метрик. Отключённый режим возвращает 404. Неверный ключ и ключ в query-параметре отклоняются. Публичный HTTPS-прокси возвращает 404 для ops endpoint.
- Метки содержат шаблоны маршрутов и ограниченные наборы методов/статусов. HTTP-тест проверяет отсутствие случайного значения из URL, ключа мониторинга и DATABASE_URL в ответе. Незнакомые статусы очереди объединяются в OTHER.
- Тест сборщика воспроизводит ошибку базы, сброс устаревших очередей и последующее восстановление. Запросы одновременно используют один текущий сбор.
- Promtool подтвердил корректность конфигурации и восьми правил. На искусственных временных рядах проверены срабатывание и восстановление тревог API и базы, а также подавление тревоги очереди при выключении канала.
- Microsoft Edge открыл реальную панель Grafana. Через неё проверено значение доступности базы. Prometheus получил три успешных scrape-target, а оба пробника вернули probe_success=1, включая проверку HTTPS с доверенным публичным сертификатом Caddy.
- Прошли 32 существующие модульные проверки и проверки локализации, две проверки мониторинга, сборка Docker-образа и проверка структуры. Аудит production-зависимостей сообщил о нуле известных уязвимостей на дату проверки.

## Исправления после проверки

При публикации портов из полностью внутренней Docker-сети панели оставались доступны только контейнерам. Добавлена отдельная сеть доступа, опубликованные порты привязаны к 127.0.0.1. Проверены адреса 3100 и 9090 с компьютера.

Одноразовый экспорт публичного сертификата первоначально мешал compose --wait из-за штатного завершения контейнера. Явная зависимость service_completed_successfully описывает его жизненный цикл. Экспортер HTTPS получает отдельный том с публичным сертификатом. Частные ключи центра остаются в томе Caddy.

## Границы

Сборщик читает общие технические показатели платформы. Бизнес-записи и схема PostgreSQL этим изменением не меняются. Пароли Grafana, её ключ шифрования и ключ метрик находятся в игнорируемой .local/monitoring.

Тревоги отображаются в панелях. Получатель внешних уведомлений требует отдельной настройки. Проверка отключённого компьютера потребует независимого работающего узла. Тестовые сбои использовали отдельную базу, контролируемый отказ сборщика и искусственные ряды, рабочие сервисы для испытания сбоев не останавливались.
