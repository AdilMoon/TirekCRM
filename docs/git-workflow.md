# Git и GitHub

Приватный репозиторий: https://github.com/AdilMoon/TirekCRM.
Рабочий каталог: D:\Projects\TirekCRM. Основная ветка: main.

По просьбе пользователя каждый успешно завершённый запрос, меняющий проект, заканчивается содержательным коммитом и отправкой в этот репозиторий. Ответы на вопросы не создают пустых коммитов. Коммит сохраняет историю локально; push отправляет её в GitHub. Push не публикует приложение и не переносит базу данных.

## Перед отправкой

1. Проверить состав изменений, пройти check:structure, typecheck, test и build; затронутые API и пользовательские сценарии проверить на отдельной тестовой организации.
2. Провести отдельное адверсариальное ревью по AGENTS.md, исправить воспроизведённые дефекты, сохранить результаты в docs/reviews/.
3. Проверить diff и staged-файлы. Не включать .env, токены, локальную БД, зависимости, кэши и результаты тестов. .env.example содержит только пример локальной настройки.
4. Создать содержательный коммит, выполнить обычный push без force и сверить SHA удалённой ветки.
5. Сообщить пользователю, что изменено, что проверено и какой коммит отправлен.

Если проверки не пройдены, исправить проблему до объявления успеха. Если сеть или авторизация не позволяют отправить код, сохранить локальный коммит и явно сообщить о неудавшемся push. Не переписывать историю.

GitHub-аутентификация хранится в системном Git Credential Manager, не в исходниках и не в remote URL. Для новых отдельных рабочих веток используется префикс codex/.
